# Limites de sécurité

Un système interchaînes dépend de plusieurs surfaces : consensus, clés de validation, contrats gateway et disponibilité des relais. Une erreur de configuration peut affecter plusieurs réseaux à la fois.

Ce parcours couvre les mécanismes exposés dans le dépôt. Aucune installation, compilation ou exécution n a été réalisée ; les contrôles et tests listés par le projet restent la référence pour vérifier une implémentation.
