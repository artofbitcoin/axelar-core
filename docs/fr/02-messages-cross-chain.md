# Messages cross-chain

Les messages entrants sont représentés par des événements et des preuves relayés vers le réseau Axelar. Les modules vérifient les signatures, les confirmations et l état du vote avant d autoriser une exécution sur la chaîne cible.

La séparation entre observation, vote et exécution limite les ambiguïtés de provenance.
