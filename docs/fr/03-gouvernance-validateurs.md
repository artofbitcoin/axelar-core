# Gouvernance et validateurs

Les validateurs participent au consensus et aux décisions de gouvernance qui paramètrent les routes et les contrats. Les modules Cosmos SDK exposent les messages, les états persistants et les contrôles d autorité.

Les mises à jour doivent rester compatibles avec les versions de contrats et les configurations réseau.
